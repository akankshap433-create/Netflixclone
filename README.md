# 🎬 Netflix Clone

A Netflix-inspired streaming platform developed as a collaborative project using React, JavaScript, HTML, CSS and Node.js.

## ✨ Features

- Netflix-style Home page
- Movies & TV Shows
- Search functionality
- Login & Subscription Plans
- User Profiles
- Kids Mode
- My List
- Continue Watching
- Movie details & trailers
- Responsive design
- Netflix-style UI

## 🛠️ Tech Stack

- React
- JavaScript
- HTML5
- CSS3
- Node.js
- Git & GitHub
